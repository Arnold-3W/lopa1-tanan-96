# Lớp A1 · THPT Tân An, Long An — 30+ Năm Tình Bạn

Trang landing page kỷ niệm hơn 30 năm tình bạn gắn kết của tập thể Lớp A1,
Trường Trung Học Phổ Thông Tân An (Long An) — niên khóa từ năm 1993.

> "Chúng ta không chỉ là bạn học cũ. Chúng ta là một phần tuổi trẻ của nhau."

## Nội dung

- **Hero** — lời mở đầu trên nền ảnh họp lớp
- **Câu chuyện** — hành trình tình bạn từ mái trường Tân An
- **Khoảnh khắc** — thư viện ảnh kỷ niệm (có xem phóng to)
- **Hành trình** — dòng thời gian 1993 → hôm nay
- **Tình bạn A1** — Yêu thương · Sẻ chia · Giúp đỡ
- **Lời nhắn gửi** — tiếp tục gắn kết và giúp đỡ nhau trong cuộc sống

## Công nghệ

Trang tĩnh thuần HTML + CSS + JavaScript, không cần build.
Mở trực tiếp `index.html` bằng trình duyệt, hoặc deploy lên Vercel.
